# Blood RNA data feasibility for early lung adenocarcinoma research

[Español](README.es.md)

An exploratory review asked whether open datasets support studying blood RNA measured before diagnosis of stage I lung adenocarcinoma within a 24-month window.

## Finding and limits

The scoped metadata review did not identify an open cohort with every required property verified for that question. This is a dataset-access and metadata finding; it does not show that useful biomarkers do not exist.

No diagnostic test or biomarker was developed or clinically validated. No predictive model was trained, and no project-specific AUC, sensitivity, or specificity was calculated. No patient-level data are included. The project does not provide medical advice.

## Work completed

The local study documented a research question, screened public cohort metadata, recorded sources and uncertainty, and prepared an offline reproduction path using metadata and synthetic test fixtures. The result should be rechecked if datasets or access terms change.

## Evidence labels

`VERIFIED` means checked against the cited records within the review scope. `INFERRED` means an interpretation from incomplete evidence. Dataset eligibility and access beyond that scope remain `NOT_VERIFIED`.
