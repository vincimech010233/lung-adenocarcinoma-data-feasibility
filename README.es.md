# Viabilidad de datos de ARN sanguíneo para investigar el adenocarcinoma pulmonar temprano

[English](README.md)

Revisión exploratoria para saber si existen conjuntos de datos abiertos que permitan estudiar ARN en sangre medido antes del diagnóstico de adenocarcinoma pulmonar en estadio I, dentro de un periodo de 24 meses.

## Resultado y límites

La revisión acotada de metadatos no identificó una cohorte abierta con todas las propiedades necesarias verificadas para esa pregunta. Es un resultado sobre disponibilidad y metadatos; no demuestra que no existan biomarcadores útiles.

No se desarrolló ni validó clínicamente una prueba diagnóstica o un biomarcador. No se entrenó un modelo predictivo ni se calcularon AUC, sensibilidad o especificidad propias. No se incluyen datos de pacientes. El proyecto no ofrece consejo médico.

## Trabajo realizado

El estudio local documentó la pregunta, revisó metadatos de cohortes públicas, registró fuentes e incertidumbres y preparó una ruta de reproducción offline con metadatos y datos sintéticos de prueba. Conviene repetir la revisión si cambian los conjuntos de datos o sus condiciones de acceso.

## Etiquetas de evidencia

`VERIFIED` significa contrastado con los registros citados dentro del alcance de la revisión. `INFERRED` indica una interpretación basada en evidencia incompleta. La elegibilidad y el acceso fuera de ese alcance siguen `NOT_VERIFIED`.
